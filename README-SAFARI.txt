# UFC PRESIDENT v2.1 — Safari / iPhone / iPad

이 버전은 Safari에서 실행할 수 있도록 PWA 구조로 준비되어 있습니다.

중요:
- iPhone/iPad에서 `.html` 파일을 파일 앱으로 미리보기 하는 방식은 Safari의 웹앱 실행 환경과 다릅니다.
- 가장 안정적인 방법은 이 폴더를 HTTPS 웹주소로 올린 뒤 Safari에서 접속하는 것입니다.
- HTTPS로 접속하면 홈 화면에 추가하여 앱처럼 사용할 수 있고, 데이터는 브라우저 저장소에 보관됩니다.

구성:
- index.html : 메인 앱
- manifest.webmanifest : 홈 화면 설치 정보
- sw.js : 오프라인 캐시
